# WeatherApp

Simple front-end Weather app scaffolded in this workspace.

## Features
- Minimal HTML/JS app in `src/`
- Tailwind CSS build with `tailwindcss` CLI

## Prerequisites
- Node.js (recommended 16+)

## Install
```bash
npm install
```

## Build CSS
```bash
npm run build
```

## Development (watch)
```bash
npm run watch
```

## Project structure
- `src/` — application source (`index.html`, `index.js`, CSS files)
- `package.json` — scripts and dependencies

## Notes
- `node_modules/` is currently committed. If you want it removed from the repo, I can add `node_modules/` to `.gitignore`, remove it from the index, and push a cleanup commit.
